# דגמי הוראה ללומד עצמאי, בסיוע AI

מיניסייט לכנס הסגל האקדמי באפקה, פתיחת שנה״ל תשפ״ז (15.10.26). תוצר של המרכז לקידום הוראה.

**דמו:** התוכן בדגמים מומצא לצורך הצגה. הכרטיסים האמיתיים ייבנו מהטופס שהמרצים ימלאו.

## מה יש באתר
- **דגמי הוראה:** קטלוג עם חיפוש וסינון, וכרטיס מלא בן 10 שדות לכל דגם.
- **התאמה לקורס שלי:** פתיחת עותק של דגם לעריכה.
- **בניית כרטיס:** טופס לפי תבנית הכרטיס, עם תצוגה מקדימה, הורדה ל-Word והדפסה.
- **צ׳קליסט לפתיחת שנה:** 19 סעיפים בחמש תחנות.

## עדכון תוכן
- דגמים: `models.json` (דגם חדש = אובייקט נוסף במערך `models`, באותו מבנה).
- צ׳קליסט: `checklist.json`.
- לוגו המרכז: `assets/center-logo.png`.

אין שלב בנייה. מספיק לערוך את הקבצים ולדחוף ל-`main`, ו-GitHub Pages מתעדכן.

## צפייה מקומית
```bash
python3 -m http.server 8000
```
ואז `http://localhost:8000`. פתיחה בלחיצה כפולה על `index.html` לא תעבוד, כי הדפדפן חוסם קריאה של קובצי JSON.
