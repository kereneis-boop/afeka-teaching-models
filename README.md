# דגמי הוראה ללומד עצמאי, בסיוע AI

מיניסייט לכנס הסגל האקדמי באפקה, פתיחת שנה״ל תשפ״ז (15.10.26). תוצר של המרכז לקידום הוראה.

**שימו לב:** הכרטיסים נכתבו על בסיס חומרי המרצים בפיילוט, וצריך לאשר כל כרטיס מול המרצה לפני פרסום.

## מה יש באתר
- **דגמי הוראה:** כל הדגמים בעמוד אחד, עם סינון לפי תחום.
- **עמוד דגם:** בקצרה, איך זה עובד, "קחו לקורס שלכם" (פרומפטים וקישורים עם כפתור העתקה), מה למדנו, ואיך להתאים.
- **צ׳קליסט לפתיחת שנה:** רשימה אחת עם אחוז מוכנות.

## עדכון תוכן
- דגמים: `data/models.js` (דגם חדש = אובייקט נוסף במערך, באותו מבנה; המבנה מתועד בראש הקובץ).
- צ׳קליסט: `data/checklist.js`.
- לוגו המרכז: `assets/center-logo.png`.

אין שלב בנייה. מספיק לערוך את הקבצים ולדחוף ל-`main`, ו-GitHub Pages מתעדכן.

## צפייה
```bash
python3 -m http.server 8000
```
אפשר גם לפתוח את `index.html` בלחיצה כפולה: הנתונים נטענים כקובצי JS ולא דורשים שרת.
